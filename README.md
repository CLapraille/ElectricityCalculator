# ElectricityCalculator

Coût réel de la recharge d'une voiture électrique à domicile (Wallonie, ORES Luxembourg, TotalEnergies myComfort Variable),
pour provisionner chaque recharge sur un compte séparé et comparer les contrats.

- Décisions et faits vérifiés : [DECISIONS.md](DECISIONS.md)
- Architecture : [ARCHITECTURE.md](ARCHITECTURE.md)

Aucune facture ni donnée personnelle n'est versionnée : ce dépôt est public.
